# bnd_sido_00_2025_2Q (경량화 버전)

- 원자료: 통계지리정보서비스(SGIS) 2025년 2분기 시도 경계 (EPSG:5179, 17개 시도)
- 원본 `.shp`가 87MB로 GitHub 웹 업로드 한도(25MB)를 넘어, Douglas-Peucker 알고리즘으로 **허용오차 2m** 단순화
  - 꼭짓점 5,433,279 → 805,002개, 파일 크기 87.0MB → 12.9MB
  - 면적 4㎡ 미만으로 줄어드는 아주 작은 섬·구멍(고리 1,122개) 제거
  - 시도별 면적 차이 최대 0.0018%
- `.dbf`(속성), `.prj`(좌표계), `.cpg`(인코딩)는 원본 그대로
- `실습5_수도권_시가화지역_추출_GEE.ipynb`는 이 경계를 다시 30m로 단순화해 사용하므로 결과에는 사실상 영향 없음
- 원본이 필요하면 SGIS(https://sgis.kostat.go.kr) 자료신청에서 내려받아 같은 이름으로 교체
